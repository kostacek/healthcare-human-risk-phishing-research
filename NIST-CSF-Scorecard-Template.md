# NIST CSF v2.0 Control Assessment Matrix


| Core Function | Category | Subcategory / Control Objective | Current Tier (1-4) | Target Tier | Remediation Action Required |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **IDENTIFY (ID)** | Risk Assessment (ID.RA) | Cyber threats are identified and documented in a risk register. | 1 | 3 | Establish centralized risk register for clinical software assets. |
| **PROTECT (PR)** | Identity Management (PR.AA) | Users are authenticated via MFA and Conditional Access rules. | 2 | 4 | Force Azure AD / Entra ID MFA prompts for remote EHR access. |
| **PROTECT (PR)** | Awareness Training (PR.AT) | Staff receive contextual, role-specific security training. | 1 | 3 | Implement monthly phishing simulations utilizing SPAF metrics. |
